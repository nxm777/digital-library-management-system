# About project

Digital library is a web application designed for book readers to track and manage their reading activity. Organize your books into reading lists, save your reading activity with reading sessions and set achievable goals with reading challenges.

## Key features:
- Organize books into reading lists
- Save your reading activity with reading sessions
- Participate in reading challenges
- Review books you've read

## Tech Stack
[![LanguagesFrameworks](https://skillicons.dev/icons?i=js,react,nodejs,express,tailwind,mongodb)](https://skillicons.dev)

- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
